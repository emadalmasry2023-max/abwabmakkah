# أبواب مكة للدهانات

موقع تعريفي عربي ثابت باستخدام HTML وCSS وJavaScript، ومهيأ للنشر على GitHub Pages دون خادم أو قاعدة بيانات أو أدوات بناء.

## بنية الملفات

- `index.html` — الصفحة الرئيسية.
- `css/style.css` — الألوان والتصميم والتنسيق المتجاوب للجوال والكمبيوتر.
- `js/script.js` — تحديث سنة الحقوق وتجهيز نموذج الاستفسار لإرساله عبر واتساب.
- `assets/` — صور الأبواب وأيقونة الموقع.

## تشغيل الموقع محليًا

افتح `index.html` في متصفح حديث. تعمل الروابط والنموذج دون إعدادات إضافية.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع مع الحفاظ على مجلدات `assets` و`css` و`js`.
3. افتح `Settings` ثم `Pages` داخل المستودع.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط `Save`.
6. انتظر اكتمال نشر GitHub Pages، ثم افتح رابط الموقع الظاهر في صفحة Pages.

**مهم:** يجب أن يكون `index.html` في جذر المصدر المختار في إعدادات Pages. لا ترفع ملف HTML وحده؛ ارفع معه مجلدات `assets` و`css` و`js`.
